## 📂 Project Overview

This repository contains my Week 4 hands-on submissions, including all 5 exercises implemented using **ASP.NET Core 8.0 Web API**. Each task demonstrates core Web API concepts such as **GET**, **POST**, **PUT**, and **DELETE** using controller-based routing and Swagger UI for testing.

---

## ✅ Hands-On Summary

| Task | Controller           | HTTP Methods      | Description                          |
|------|----------------------|-------------------|--------------------------------------|
| 1    | `FruitsController1`  | `GET`             | Returns a static list of fruits      |
| 2    | `FruitsController2`  | `GET`             | Returns all fruits & by index        |
| 3    | `FruitsController2`  | `POST`            | Adds a new fruit to the list         |
| 4    | `FruitsController4`  | `PUT`             | Updates a fruit by index             |
| 5    | `FruitsController5`  | `DELETE`          | Deletes a fruit by index             |

## 🚀 How to Run This Project

1. Clone or download this repository.
2. Open `WebApi_Handson1.sln` in **Visual Studio 2022**.
3. Set `WebApi_Handson1` as the **Startup Project**.
4. Run the project using `F5` or `Ctrl+F5`.
5. Swagger UI will launch automatically in the browser.
